# 拟态 x Apple 融合风格文档（v1.0）

## 1. 风格定位
以 **Apple 的清晰层级与克制秩序** 为骨架，叠加 **Soft UI（拟态）的轻触感**。  
目标是“专业工具感 + 现代系统感”，避免厚重拟物和低对比。

## 2. 视觉关键词
- 清爽
- 轻柔
- 克制
- 可操作感
- 高可读
- 系统级一致性

## 3. 设计原则
- 信息结构遵循 Apple：层级清晰、留白充足、内容优先。
- 拟态只用于交互控件，不覆盖整页容器。
- 动效短而稳，反馈明确，不做炫技动画。
- 所有状态（默认/悬停/按下/禁用/聚焦）必须可区分。
- 可访问性优先，文本与背景对比满足可读性要求。

## 4. 与 Apple 风格异同
**相同点**
- 简洁、克制、注重秩序。
- 强调一致性和反馈。
- 注重质感但不过度装饰。

**不同点**
- 拟态强调凹凸触感；Apple 更强调材质层级与清晰边界。
- 拟态容易低对比；Apple 对可读性要求更严格。
- 拟态常“全局一套阴影”；Apple 按层级精细控制视觉强度。

## 5. 融合策略（推荐比例）
- Apple 70%
- 拟态 30%

执行规则：
- 容器卡片采用 Apple 式干净分层。
- 按钮/输入框/开关/滑块使用轻拟态阴影。
- 仅主操作控件强化触感，次要控件保持平面简洁。

## 6. 设计 Tokens（建议起始值）
- 背景色：`#EEF1F6`
- 主文字：`#1F2937`
- 次文字：`#6B7280`
- 主色：`#2F6FED`
- 成功：`#2E9B57`
- 警告：`#C58A1A`
- 错误：`#C64B4B`
- 圆角（卡片）：`14px`
- 圆角（控件）：`10px`
- 外阴影：`0 4px 12px rgba(17,24,39,0.12)`
- 内阴影：`inset 0 1px 3px rgba(255,255,255,0.7), inset 0 -2px 6px rgba(17,24,39,0.10)`
- 动效时长：`120ms - 180ms`
- 动效曲线：`ease-out`

## 7. 组件规范
- 按钮：默认轻凸，按下切为轻内凹；主按钮可提高颜色对比。
- 输入框：常态内凹，聚焦时加清晰 focus ring（不要只靠阴影）。
- 开关/滑块：保留触感，但轨道与拇指对比要明确。
- 卡片/面板：弱阴影、强结构；不要叠太多拟态层。

## 8. 交互与动效
- Hover：亮度或阴影微调。
- Active：轻微缩放（约 `0.98`）+ 阴影反转。
- Focus：统一高对比描边（2px）。
- 禁用：降低饱和度和对比，不改变布局。

## 9. 禁止项
- 全页面重拟态（会显脏且影响可读性）。
- 浅灰字配浅灰底。
- 阴影半径过大导致糊边。
- 单靠颜色表达状态（必须有形态/图标/文案辅助）。

## 10. 一句话规范
**“结构按 Apple，触感用拟态，始终以可读性和效率为第一优先级。”**
